# Community translation sources — 葉月ゆら (Hatsuki Yura)

A decade of fan translation/transliteration is scattered across dead and living blogs. This is a
**verified index of where it lives** so the community can gather it. Rule of thumb (per the
archive owner): **if a translation is English (not Chinese or Vietnamese), it's almost certainly
one of ours.**

For any dead/patchy link, pull the archive: `https://web.archive.org/web/2*/<url>`
(Wayback also keeps per-post snapshots — search the exact post URL.)

Last verified: 2026-08-08. ✓ = confirmed reachable this session · ◐ = confirmed exists via search,
liveness not re-checked · ⚠ = likely dead, use Wayback.

## NOT ours — exclude

- **Petalite Yuu** (petayuuchan.wordpress.com) — **Vietnamese** (JP/romaji + VN). *But* it credits its
  English source as "Musical Tales of Yura Hatsuki" (= meriole) — useful as a pointer, and its
  romaji is reusable.
- **Ảo Mộng** (systina2642.wordpress.com) — **Vietnamese**.
- **sonichits.com** — auto-aggregator (scraped), not a real translation. Verify before trusting.

## How to gather (for the community)

1. Start with the two **dedicated** sources (hatsukiyuralyrics.blogspot, meriole) — they cover the most.
2. For each dead link, Wayback the **exact post URL**, not just the domain — post snapshots survive
   even when the blog front page is gone.
3. Drop found text into the schema (`SCHEMA.md`): per album/track, `jp` / `romaji` / `en`, each with
   the translator's name in `by` so they're credited in the app.
