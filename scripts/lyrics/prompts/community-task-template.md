### Conventions (short version)

- **Romaji:** modified Hepburn, long vowels spelled out (`ou`, `uu`, `ei`), `wa/e/wo` for
  particles. Transliterate what is **sung**, not the dictionary reading — Yura's lyrics love
  ateji (e.g. 運命 sung as *sadame*). Use the booklet furigana if you have it.
- **English:** faithful to the images first, then make it read as poetry. Keep names as names.
  Match the song's mood (gothic / fairy-tale). Don't add imagery that isn't there.
- Full conventions: `conventions.md`.
